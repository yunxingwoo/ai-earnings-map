# AI 算力财报全景 · 微信小程序部署指南

## 〇、这个应用是什么

「AI 算力财报全景」是一个**纯静态（零构建）的 AI 算力产业链财报研究工具**：

- 覆盖 **109 家 AI 算力产业链公司 / 15 个产业环节**（材料 → EDA → 设备 → 晶圆 → 封测 → 存储 → 芯片 → 整机 → 光互联 → PCB → 供电散热 → 云厂 → 能源 → 大模型 → 应用）。
- 所有数字均来自**官方财报 / IR / 监管文件**（SEC EDGAR、台交所 mops、巨潮、港交所等），每个指标都回链溯源，缺失不编造。
- 核心能力：营收 **YoY/QoQ 实时计算**、**信号灯**（🟢加速上行 / 🟡减速温和 / 🔴负增 / ⚪不足）、**Kill Switch 监测**（云厂 capex 拐点）、**时滞传导曲线**、**估值散点**、**交叉验证 / 数据缺口墙**。
- 已做移动端适配，可生成二维码在微信里点开浏览器查看。

## 一、小程序化方案说明

小程序运行环境没有浏览器 DOM，**不能直接跑这套 HTML/CSS/JS**。业界最稳妥的做法是做一个**小程序壳**，用 `<web-view>` 组件全屏加载你已经托管在某个「自己可控域名」上的站点地址。站点本身已是移动端适配好的，在 web-view 内部渲染效果与手机浏览器一致。

本仓库的 `miniprogram/` 就是这个壳：

```
miniprogram/
├── project.config.json     # 工程配置（改 appid）
├── sitemap.json
├── app.js / app.json / app.wxss
├── config.js               # ★ 改 WEBVIEW_URL 为你部署好的站点地址
├── pages/index/            # 单页：<web-view> 承载站点
└── README.md               # 本文件
```

## 二、你（账号级）必须完成的两件事

这两件事需要你的微信/域名账号权限，我无法代做：

1. **一个微信小程序 AppID** —— 在 https://mp.weixin.qq.com 注册小程序账号后获取。
2. **一个你拥有并可控的 HTTPS 域名** —— 用于托管 `site/` 目录，并在小程序后台配置为「业务域名」。

### ⚠️ 为什么不能直接用现有沙箱链接

现有 `*.app.workbuddy.link` 是 WorkBuddy 的域名，**你无法在其根目录放置微信的校验文件 `MP_verify_xxxx.txt`**，因此无法加入「业务域名」白名单。

- 该链接**适合**：生成二维码 → 微信里点开**浏览器**看（分享卡片 / 扫码即用）。
- 该链接**不适合**：嵌进小程序 `web-view`（会被微信拦截）。

## 三、部署步骤

### 第 1 步：把站点部署到一个可控域名

推荐使用 **EdgeOne Pages**（你已有连接器，免费 · CDN · 不休眠，正好也满足你之前"不休眠托管"的需求）：

1. 在连接器管理中 **连接 EdgeOne Pages**，并**绑定一个你自己的自定义域名**（如 `map.yourdomain.com`）。
2. 把本仓库的 **`site/` 目录整体部署上去**（`site/` 是纯前端拷贝，零构建，直接传静态文件即可）。
3. 部署完成后访问 `https://你的域名/index.html`，确认能正常打开、数据正常。

> 备选托管：你自己的服务器 / GitHub Pages（自定义域名）/ Vercel / Netlify（自定义域名）等，只要能放根目录文件 + 支持 HTTPS 即可。

### 第 2 步：配置小程序后台「业务域名」

1. 登录 https://mp.weixin.qq.com → **开发 → 开发管理 → 开发设置 → 业务域名**。
2. 添加你的域名，微信会给你一个 `MP_verify_xxxx.txt` 下载。
3. 把这个文件放到该域名的**根目录**（确保 `https://你的域名/MP_verify_xxxx.txt` 能直接访问），然后在后台点击校验通过。

### 第 3 步：填好工程配置

- 打开 `miniprogram/config.js`，把 `WEBVIEW_URL` 改为 `https://你的域名/index.html`。
- `miniprogram/project.config.json` 的 `appid` **已填好** `wx9cd5dc45080d91bc`（你的小程序账号），无需再改。

### 第 4 步：用微信开发者工具预览 / 上传 / 发布

1. 打开**微信开发者工具** → 导入项目 → 选择 `miniprogram/` 目录。
2. 本地调试时勾选「**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**」。
3. 预览（扫码真机查看）→ 上传代码 → 提交审核 → 发布。
4. 审核通过后会生成**小程序码**，可分享给微信好友/群。

## 四、合规提示（重要）

本应用展示上市公司财报数据、估值、景气度信号，属于「财经 / 数据」内容，微信小程序对金融类目审核较严：

- 建议将小程序定位为 **「产业研究 / 数据可视化工具」**，仅做信息展示，避免出现「荐股」「投资建议」「收益率承诺」等表述。
- 若仅信息展示，通常可用「工具」或「资讯」类目；若选择「金融-股票/基金」类目，可能需要相应资质（许可证等）。
- `web-view` 内嵌入的 H5 内容同样需符合微信外链内容规范。
- 最终以微信审核结果为准。

## 五、更新数据后如何同步到小程序

数据更新发生在仓库根目录（`data/*.js` 等），部署用的副本是 `site/`。发布新数据后：

1. 重新把最新的 `site/` 同步到 EdgeOne Pages（重新部署一次）。
2. 小程序**无需重新发版**——`web-view` 每次打开都拉取线上最新站点。

> 建议把 `site/` 的同步 + 部署也接到自动化里（如同 PC/手机端分享链接那样），做到数据一更新、小程序自动生效。
